# YKS Takip

YKS sayısal hazırlık sürecimi takip etmek için geliştirdiğim kişisel bir uygulama. Günlük görev takibi, deneme netlerini kaydetme, hata defteri, konu ustalık haritası, kaynak takibi ve motivasyon rozetleri gibi özellikler içeriyor.

## Özellikler

- 📅 Aylık ve günlük görev planı, tamamlama takibi ve seri (streak) sistemi
- 📊 Deneme net takibi (TYT/AYT), otomatik net grafiği ve hedef karşılaştırma
- 📖 Hata defteri — 2-7-21 gün aralıklı tekrar programıyla
- 🗺️ Konu bazlı ustalık haritası (derslere göre gruplanmış ilerleme)
- 📚 Kaynak/kitap takibi (tamamlanan soru, doğruluk oranı)
- ⏱️ Gerçek süreli TYT deneme simülasyonu
- 🏆 Motivasyon rozetleri ve haftalık performans raporu

## Teknolojiler

- HTML, CSS, JavaScript (vanilla)
- Veri saklama: `localStorage`
- Android paketleme: [Capacitor](https://capacitorjs.com)

## Kurulum (Web)

`www/index.html` dosyasını herhangi bir tarayıcıda doğrudan açabilirsin.

## Kurulum (Android)

```bash
npm install
npx cap open android
```
